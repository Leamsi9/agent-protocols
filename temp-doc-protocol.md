# Temporary notes

Create working notes only when they help the task. Command output can remain in
untracked task scratch space; `docs/temp/<feature>/` is available for repository
notes. Neither location is required when no note is useful. Keep credentials,
private data and original private transcripts out of Git.

Retain information because future work needs it, not because it was generated.
Put a durable decision or useful result in the existing plan, review or commit
when appropriate. Disposable outputs and repeated snapshots do not need promotion
into history, ledgers or new documents.

Remove owned scratch files when they are no longer useful. Preserve unrelated
work and notes still in use. Cleanup needs no artifact-by-artifact dispositions,
retention explanations, empty-directory proof or separate gate. Temporary notes
are not the job's canonical state and do not belong in durable plan indexes.
